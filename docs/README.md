## Components

### Wazuh - SIEM / Centralized Security Analysis and Visualization Platform

Wazuh is the central hub for log analysis and alerting. The Wazuh Agent installed on the Windows endpoint collects Windows and Sysmon events as well as Suricata's JSON alerts. These events are forwarded to the Wazuh Manager, where Wazuh's analysis and detection rules processes the collected data and generates alerts when applicable.

The Wazuh Dashboard provides a centralized interface for searching, filtering, investigating, and visualizing security events and alerts.

---

### Sysmon - Windows Endpoint Telemetry Provider

Sysmon provides detailed Windows endpoint telemetry beyond default Windows logs. It records security-relevant activities such as process creation, network connections, DNS queries, file creation, registry activity, and other system events depending on the configured Sysmon policy.

Sysmon generates endpoint telemetry on the Windows machine, which is collected by the Wazuh Agent and forwarded to the Wazuh Manager for analysis.

---

### Suricata - Network Intrusion Detection System (NIDS)

Suricata monitors network traffic across the Windows endpoint and analyzes packets against its configured detection rules. When traffic matches a detection signature, Suricata generates an alert containing information such as the source and destination addresses, protocol, signature, severity, and action. These events are written to Suricata's `eve.json` log file.

Suricata is the network-level detection component and uses both its enabled ruleset and project-specific rules when required.

---

### Python Alert Monitor - Custom Alert Monitoring Component

The Python Alert Monitor is a custom component developed for this project. It reads Suricata's `eve.json` file and monitors the alerts generated by Suricata. Selected alert fields, such as the timestamp, source and destination information, protocol, signature, signature ID, severity, and action, are extracted and processed by the program.

The Python component handles them separately from the main Wazuh pipeline. It provides an additional lightweight mechanism for monitoring and retaining Suricata alerts locally.

---

### SQLite - Local Alert-History Datastore

SQLite provides lightweight local storage for the alerts processed by the Python Alert Monitor. The extracted Suricata alert information is stored in the `soc_alerts.db` database, to retain alert history and perform SQL-based queries for analysis and verification.

SQLite does not replace Wazuh's centralized alert storage or Dashboard. It serves as the local datastore for the project's custom Python monitoring component.
