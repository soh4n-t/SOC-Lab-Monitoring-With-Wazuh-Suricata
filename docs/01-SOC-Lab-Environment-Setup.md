# 01 - SOC Lab Environment Setup
## Overview
Setting up a lab with 3 virtual machines. It consists of:
1. Kali Linux
2. Windows 10
3. Ubuntu Server
  
### 1. Kali Linux
It generates controlled network traffic and runs authorized security tests against the monitored Windows 10 endpoint.
It is the attacker.
It is used for:
  - Security testing
  - Network testing
  - Traffic generation
  - Attack simulation
  
### 2. Windows 10
Security monitoring tools are installed on the Windows 10 to collect endpoint and network security telemetry.
It is the Wazuh Agent.
It is used for:
  - Endpoint monitoring
  - Process monitoring
  - File activity monitoring
  - PowerShell activity monitoring
  - Network traffic monitoring

Components installed in Windows include:
  - Sysmon
  - Suricata
  - Npcap
  - Python
  
### 3. Ubuntu Server
It receives and processes security events generated by monitored endpoints.
It acts as the Wazuh Manager.
It is used for:
  - Centralized event collection
  - Security alert processing
  - Security monitoring

## Host System
It is the Wazuh dashboard.
It is used to:
  - Run the three virtual machines
  - Access the Wazuh Dashboard through a web browser
Before doing anything, first check for connectivity between the three virtual machines.
Arrange the 3 machines in the same subnet (I prefer Nat).
